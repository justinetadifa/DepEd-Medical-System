# GitHub baseline

[Ahmed-Al-Aini/Hospital-Management-System](https://github.com/Ahmed-Al-Aini/Hospital-Management-System) is an MIT-licensed PHP MVC hospital system with PDO, MySQL, patient records, and a browser interface. The source used for this starter was pinned to commit `73de4be41bc0ae54a4457bc57be3171f9885b3db`.

- `app/Database.php` adapts `config/database.php` for the local clinic database.
- `app/security.php` adapts token handling from `core/csrf.php`.
- The original versions of those files are in `upstream-source`. The upstream MIT notice is in `UPSTREAM-LICENSE.txt`.
- `Hospital-Management-System-source.zip` contains the upstream application source and license from the pinned commit. The demo database dump, logs, screenshots, and bundled third-party assets are omitted. The full original distribution is at the GitHub link above.

The employee/report screens, database tables, and OCR bridge in the runnable app were created for the DepEd workflow. The original hospital repository remains available at the link above.
